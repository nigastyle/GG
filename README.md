# GG
GG — Silkroad Helper

GG — это лёгкий desktop-helper для Silkroad Online, созданный для удобной работы с макросами, инжектами и кликами без случайного спама в браузере или чатах.

Программа ориентирована на практичность, контроль и безопасность действий.

🚀 Возможности

⌨️ Глобальный захват клавиатуры
Управление через NumPad / горячие клавиши

💬 Отправка сообщений и инжектов (INT / STR)
Поддержка нескольких слотов, пустые строки игнорируются

🖱 Кликер
Для игровых механик (в том числе “пылесос”)

🪟 Работа строго в выбранном окне
Макросы выполняются только если активно нужное окно
(никаких сообщений в браузер, Discord и т.п.)

🎯 Выбор окна назначения
Можно зафиксировать конкретное окно игры (HWND)

⚠️ Panic-режим
Мгновенная остановка всех действий одной клавишей

🔄 Автообновление через GitHub Releases
Программа сама проверяет новые версии и предлагает установить обновление

🧾 Лог действий
Понятный лог в реальном времени

🔄 Обновления

GG умеет проверять обновления напрямую через GitHub Releases.

сравнивает версии

показывает описание релиза

скачивает и запускает установщик .exe

Если сеть или прокси мешают — есть безопасный fallback.

🛠 Установка

Перейди в Releases

Скачай последний .exe

Установи и пользуйся

⚠️ Важно

Программа не является читом

Всё, что она делает — это автоматизация ввода и кликов

Используешь на свой страх и риск, как и любые макросы

GG — Silkroad Helper (EN)

GG is a lightweight desktop helper for Silkroad Online, designed for safe and controlled macro usage without accidentally spamming browsers or chats.

It focuses on practicality, control, and predictable behavior.

🚀 Features

⌨️ Global hotkeys support

💬 Message & inject macros (INT / STR)

🖱 Clicker

🪟 Works only in the selected game window

🎯 Target window selection (HWND)

⚠️ Panic mode (instant stop)

🔄 Auto-update via GitHub Releases

🧾 Real-time activity log

🔄 Updates

GG can check for updates directly from GitHub Releases:

compares versions

shows release notes

downloads and launches the installer automatically

🛠 Installation

Go to Releases

Download the latest .exe

Install and run

⚠️ Disclaimer

This is not a cheat

It only automates input and clicks

Use at your own risk
